# Project health

Use these branches only when directed by `SKILL.md`.

## Place the frontier in the project horizon

Start from the cheapest authoritative roadmap, scope baseline, milestone map, or dependency rollup. Expand only unresolved areas.

Establish:

- The intended outcome and dated or versioned scope baseline.
- The current phase and achieved milestone outcomes.
- Each top-level adopted scope area's state: achieved, remaining, excluded, or unknown.
- The remaining critical path, blockers, and material dependencies.
- Scope added, removed, or still undecided since the baseline.

Estimate completion from comparable or explicitly weighted outcomes. State the denominator, method, and lifecycle state credited; use item counts only when the items are genuinely comparable.

The horizon is reconciled when every top-level adopted scope area is classified and the current phase and critical path are supported. If no authoritative baseline exists, report the missing project model instead of inventing a percentage.

## Assess delivery pace

Use this branch when pace is requested or materially affects the next move. Choose an explicit time window and comparator: a plan, deadline, forecast, demonstrated capacity, or prior comparable window. Prefer the smallest decision-relevant set of outcome signals, such as integrated milestone throughput, cycle time, blocker age, work in progress, and review or rework rate.

Rate schedule health:

- **Healthy** — the evidence-based forecast supports the target with known risks.
- **At risk** — the trend, an interim milestone, or the critical path credibly threatens the completion target.
- **Off track** — the governing completion target is missed or the current forecast misses it.
- **Not assessable** — the target, timing, capacity, or comparator is absent.

With historical evidence but no target, report whether delivery is accelerating, stable, or slowing while keeping schedule health **Not assessable**. State the window, comparator, evidence, and confidence.

The pace assessment is complete when its rating or trend is traceable to time-bounded evidence and every missing input that affects confidence is explicit.
